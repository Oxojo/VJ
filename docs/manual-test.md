# Manual test checklist

本番に使う Windows PC で実施し、結果を `performance-results.md` に追記します。最初は再配布可能な短い H.264/MP4 と PNG/JPEG を使います。

## 1. 起動と出力

1. アプリを起動し、Operator と `VJ System — Output` の2ウィンドウが出ることを確認する。
2. Output が黒で始まり、Operator の `BLACKOUT ON` が点灯していることを確認する。
3. L1 の単色、L3 の4 generator を発火し、暗転解除後に表示されることを確認する。
4. Output を外部画面へ移動して fullscreen にする。
5. 外部画面を抜き、Output が主画面へ回収されることを確認する。
6. `B` キーで暗転が切り替わり、テキスト入力中は切り替わらないことを確認する。

## 2. メディア

1. 720p30、720p60、1080p30、1080p60 の H.264/MP4 を各1本以上登録する。
2. L1/L2 へ割り当てられ、発火中の PGM を維持したまま次素材を準備することを確認する。
3. 同じレイヤーのパッドを連打し、最後の要求だけが発火することを確認する。
4. ファイルを一時的に移動し、現在の PGM を維持して対象スロットが失敗状態になることを確認する。
5. 代表素材を100周させ、ループ境界の黒フレーム、停止、目立つ間を録画で確認する。
6. PNG の透明縁に黒い輪郭が出ないことをテスト画像で確認する。

## 3. APC Mini MK2

1. 通常の Clip Launch / Session 系モードにして接続する。
2. MIDI IN / OUT に manufacturer と port 名が表示されることを確認する。
3. 全64パッドを押し、画面の同じ位置が反応することを MIDI monitor で記録する。
4. フェーダー1〜9が CC 48〜56、channel 1 として届くことを確認する。
5. Scene 呼び出し後、物理フェーダーがソフト値を横切るまで値が飛ばないことを確認する。
6. 空、割り当て、準備中、再生中、失敗の LED 表示を確認する。
7. 演奏中に USB を抜き、映像が継続することを確認する。
8. 再接続後に LED が復元され、フェーダー pickup が再設定されることを確認する。

## 4. Audio input

1. DJ ミキサーの適切な line out をオーディオインターフェースの line input へ接続する。
2. Windows の通常録音デバイスとして見える入力を選択する。
3. RMS / Low / Mid / High が動き、無音時に0へ戻ることを確認する。
4. echo cancellation、noise suppression、auto gain control を無効化できたか OS / device 設定で確認する。
5. VJ アプリの解析音がスピーカーや OBS へ出ていないことを確認する。
6. 入力を切断し、音声反応が減衰して動画と BeatClock が継続することを確認する。

## 5. Tempo and scenes

1. 60、90、128、160、180、220、260、300 BPM を順に設定する。
2. 各点で Tap、½、×2、Downbeat、Nudge を操作する。
3. beat / bar / four-bars 境界で二重発火や過去イベントの連続発火がないことを確認する。
4. 260 / 300 BPM で細かい1/4拍表現を Standard と Fallback で比較する。
5. Scene を保存・呼び出しし、BPM、量子化、暗転、Freeze、masterBrightness、機器選択が変わらないことを確認する。

## 6. OBS and 60-minute run

1. OBS に Window Capture を追加し、タイトル `VJ System — Output` を選ぶ。
2. カーソルをオフにし、クライアント領域をキャプチャする。
3. OBS を 1920×1080 / 60fps に設定し、外部画面へ移動した Output を録画する。
4. 8〜16小節ごとに素材、Scene、色、歪み、残像を操作する。
5. APC と Audio をそれぞれ一度切断・再接続する。
6. 10分ごとに CPU、GPU、メモリ、FPS、DROP を記録する。
7. 60分後、長い停止、黒フレーム、音漏れ、意図しない Scene 変更を録画で確認する。
8. Standard が目標を満たさない場合は同じ素材・操作で Light、Fallback の順に比較する。

## Pass criteria

- Ready 済み素材とパラメーター操作の反映が p95 50ms 以内
- 量子化適用が通常1描画フレーム程度
- 音声立ち上がりから映像変化が100ms程度以内
- 安定区間の欠落フレーム比率が1%以下
- ウォームアップ後にメモリ増加が継続しない
- 60分間に長い停止、意図しない黒フレーム、解析音の出力がない
